Três versões para escolher

Mesmo conteúdo, três mundos. Abra cada uma no computador e no celular. Role para seguir a história, arraste para explorar o mapa, aperte M para ver tudo de cima.

  1. 5

    1 · Contagem

    O site é a ponta de um filme. Os capítulos contam 1, 2, 3, 4 até o rolo com os seus vídeos, numa página só: cada cena fica presa na tela enquanto a rolagem a conta.

    Abertura: o nome com luz em movimento · Objeto: editor de curva de tempo Abrir a versão 1

    2 · Concreto

    O mapa é um poema concreto: SAVIO desce e cada capítulo cruza uma letra do nome. Afaste para ler o poema, aproxime para ler o capítulo.

    Abertura: as letras caem até formar o nome · Objeto: um bicho de placas articuladas Abrir a versão 2

    3 · Cartaz

    Um muro de cartazes de rua. Tipos de madeira em escala de prédio, cortados pela borda; a palavra mais alta é a porta para cada capítulo.

    Abertura: três cortes secos · Objeto: letras de madeira com física Abrir a versão 3
